## Engineering standards (managed by build-protocol)

Before planning or changing code in this repository:

1. Read `.standards/profile.md`. It names this project's type, commands, protected paths
   and which standards apply here. Where the profile and a standard disagree, the profile wins.
2. Read only the `.standards/*.md` files the profile marks as applicable to the task at hand.
3. Instructions the user gives in the conversation override both.

Existing code keeps its current style unless the task is to refactor it. New code follows the standards.
Edit this project's rules in `.standards/profile.md`, not inside this block: the block is rewritten on re-install.
