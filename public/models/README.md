# תיקיית מודלים תלת-ממדיים (`public/models`)

הנח כאן קבצי מודלים תלת-ממדיים כדי שהמשחק והמעבדה יוכלו לטעון אותם ישירות (דרך `/models/<filename>`).

## מבנה תיקיות מומלץ (אופציונלי, או ישירות בתיקייה זו):
- `public/models/characters/` — דמויות (שחקן, גמדים, תושבים, סוחרים)
- `public/models/animals/` — חיות (אייל, כבשה, סוס, זאב, ארנב וכו')
- `public/models/weapons/` — כלי נשק וציוד (חרב, קשת, מגן, גרזן)
- `public/models/buildings/` — מבנים, עצים ואובייקטים במפה

## פורמטים מומלצים:
1. **`.glb`** (הכי מומלץ) — קובץ יחיד שכולל בתוכו את הגיאומטריה, הטקסטורות והאנימציות.
2. **`.gltf`** (+ קבצי `.bin` וטקסטורות נלווים באותה תיקייה).
3. **`.fbx` / `.obj`** — נתמכים גם כן ב-Three.js במידה ואין `.glb`.
